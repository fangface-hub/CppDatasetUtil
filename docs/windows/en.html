CppDatasetUtil API

NAME

CppDataSet - recursive Dataset value with optional comments

SYNOPSIS

#include <Dataset.h>
class Dataset;

DESCRIPTION

Dataset holds null, bool, a signed 64-bit integer, double, string, map or array. Map and array elements are also Dataset values. Each value may have its own comments. Maps are sorted by key and arrays preserve their order. Copying and moving preserve both values and comments.

TYPES AND CONSTRUCTORS

Dataset::Map is std::map<std::string, Dataset>, Dataset::Array is std::vector<Dataset>, and Dataset::Value is a std::variant of the supported types. The default constructor creates null without comments. Constructors also accept nullptr, bool, int, std::int64_t, double, const char*, std::string, Map and Array. A null const char* throws std::invalid_argument.

ACCESS

operator[](const std::string& key) Accesses a map entry. A mutable null value becomes an empty map, and a missing key is inserted with a null value. The parent value's comments are preserved. Const access changes nothing and throws std::out_of_range if the key is missing. Access to a non-map value throws std::logic_error.

operator[](std::size_t index) Accesses an array element without inserting it. Indices start at zero. A non-array value throws std::logic_error; an out-of-range index throws std::out_of_range. Replacing the parent Dataset invalidates references to its elements.

value() const noexcept Returns a const reference to Value. On a type mismatch, std::get throws std::bad_variant_access and std::get_if returns a null pointer.

COMMENTS

comments() const noexcept Returns a const reference to the comments in their stored order.

set_comments(std::vector<std::string> comments) Replaces the comments. Specify text without a leading #; embedded line breaks produce multiple comment lines. YAML and TOML require valid UTF-8 and reject unsupported control characters and Unicode line separators. TOML comments that cannot be placed syntactically are omitted. CSV and JSON do not save comments. Assignment or a successful Load also replaces existing comments.

FILES

Load(const std::string& path) Loads CSV, JSON, YAML or TOML based on the case-insensitive extension .csv, .json, .yaml, .yml or .toml. Comments are not loaded. Success replaces the value and comments; failure leaves the Dataset unchanged. I/O errors, invalid input, and unsupported extensions or values throw std::runtime_error.

static LoadDirectory(const std::string& path, bool recursive = false) Returns a std::list of path and Dataset pairs sorted by path. Subdirectories are traversed only when recursive=true. Unsupported extensions are ignored. Symbolic links to files and directories are followed; a target reached by multiple paths is loaded once per path. Returned paths retain the supplied directory and link names. A file link's own extension determines its format. Cycles, broken links, unreadable entries and failed files are skipped with a warning on stderr. A starting directory that cannot be opened throws std::runtime_error. Comments are not loaded.

Save(const std::string& path) const Saves according to the extension. CSV requires an array of nonempty maps with identical keys and string values; an empty array produces an empty file. The TOML root must be a map and null is unsupported. Non-finite floating-point numbers cannot be saved. YAML and TOML save representable comments. Serialization precedes opening the file, but a write error can leave it truncated or incomplete. I/O errors, unsupported extensions, and values or comments that cannot be represented throw std::runtime_error.

CSV uses the first row as column names and loads each subsequent row as a map of strings. Duplicate names and inconsistent field counts are errors. YAML resolves supported core scalars and rejects multiple documents, duplicate anchors, recursive aliases and unsupported tags. TOML date/time values and non-finite numbers cannot be loaded.

EXAMPLE

#include <Dataset.h>
#include <string>
#include <variant>
Dataset data;
data["server"]["host"] = "localhost";
data["server"]["host"].set_comments({"Server address"});
data.Save("config.yaml");
Dataset loaded;
loaded.Load("config.yaml");
const auto& host = std::get<std::string>(
    loaded["server"]["host"].value());

DATA-DRIVEN TESTING

Run the following GoogleTest example from the project root. Dataset reads two files in Tests/data/server-config; the independent ServerConfig model is the test subject. Its endpoint and enabled state are compared with expected values. The file-count and nonempty-case checks help detect skipped data files. Each file contains cases with input and expected values:

Tests/data/server-config/basic.json

{
  "cases": [
    {
      "input": {"host": "localhost", "port": 8080, "enabled": true},
      "expected": {"endpoint": "localhost:8080", "enabled": true}
    },
    {
      "input": {"host": "127.0.0.1", "port": 0, "enabled": false},
      "expected": {"endpoint": "127.0.0.1:0", "enabled": false}
    }
  ]
}

Tests/data/server-config/alternate.toml

[[cases]]
[cases.input]
host = "example.net"
port = 443
enabled = false

[cases.expected]
endpoint = "example.net:443"
enabled = false

#include <cstddef>
#include <cstdint>
#include <string>
#include <utility>
#include <variant>

#include <gtest/gtest.h>
#include "Dataset.h"

class ServerConfig {
 public:
  ServerConfig(std::string host, std::int64_t port, bool enabled)
      : host_(std::move(host)), port_(port), enabled_(enabled) {}

  std::string endpoint() const { return host_ + ":" + std::to_string(port_); }
  bool enabled() const { return enabled_; }

 private:
  std::string host_;
  std::int64_t port_;
  bool enabled_;
};

TEST(ServerConfigTest, BuildsEndpointAndStoresEnabledState) {
  const auto files = Dataset::LoadDirectory("Tests/data/server-config");
  ASSERT_EQ(files.size(), 2u);
  for (const auto& [path, dataset] : files) {
    SCOPED_TRACE(path);
    const auto& cases = std::get<Dataset::Array>(dataset["cases"].value());
    ASSERT_FALSE(cases.empty());
    for (std::size_t i = 0; i < cases.size(); ++i) {
      SCOPED_TRACE(i);
      const Dataset& input = cases[i]["input"];
      const Dataset& expected = cases[i]["expected"];
      const ServerConfig server(std::get<std::string>(input["host"].value()),
                                std::get<std::int64_t>(input["port"].value()),
                                std::get<bool>(input["enabled"].value()));
      EXPECT_EQ(server.endpoint(),
                std::get<std::string>(expected["endpoint"].value()));
      EXPECT_EQ(server.enabled(), std::get<bool>(expected["enabled"].value()));
    }
  }
}
