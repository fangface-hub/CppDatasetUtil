CppDatasetUtil API

名前

CppDataSet - コメントを付けられる再帰的な Dataset 値

書式

#include <Dataset.h>

class Dataset;

説明

Dataset は null、真偽値、符号付き 64 ビット整数、double、文字列、 マップ、配列を保持します。マップと配列の要素も Dataset であり、各値に個別のコメントを設定できます。 マップはキー順、配列は挿入された順序で保持されます。 コピーやムーブでは値とコメントが一緒に扱われます。

型

Dataset::Map std::map<std::string, Dataset> です。

Dataset::Array std::vector<Dataset> です。

Dataset::Value null、bool、std::int64_t、double、std::string、Map、Array を 保持する std::variant です。

long long、std::size_t、unsigned などその他の整数型は、符号付き 64 ビット整数として保持されます。int64 の範囲を超える符号なし値は std::out_of_range を送出します。const char* 以外のポインターは bool に変換されず、コンパイル時にエラーになります。

コンストラクター

Dataset() はコメントのない null 値を作成します。nullptr、bool、int、 std::int64_t、double、const char*、std::string、Map、Array からも 構築できます。const char* に null ポインターを指定した場合は std::invalid_argument を送出します。

size() const noexcept マップまたは配列の要素数を返します。それ以外の値では 0 を返します。

contains(const std::string& key) const noexcept 値が key を含むマップの場合に true を返します。

push_back(Dataset value) 配列の末尾に要素を追加します。null の場合は先に空の配列に変換し、コメントは保持します。それ以外の型では std::logic_error を送出します。

erase(const std::string& key) マップの要素を削除し、存在していたかどうかを返します。マップ以外では std::logic_error を送出します。

erase(std::size_t index) 配列の要素を削除し、後続の要素を前へ詰めます。配列以外では std::logic_error、範囲外では std::out_of_range を送出します。

value() noexcept Value への変更可能な参照を返します。別の型の値を代入すると値が置き換わり、コメントは保持されます。

operator==, operator!= 値とコメントを再帰的に比較します。NaN は自分自身とも等しくありません。

要素へのアクセス

operator[](const std::string& key) マップの要素を参照します。変更可能な Dataset が null の場合は空のマップに 変換し、存在しないキーには null 値を挿入します。その際、この値自身の コメントは保持されます。const Dataset に対するアクセスでは変更や挿入は 行いません。マップ以外へのアクセスは std::logic_error を送出し、 const アクセスでキーが存在しない場合は std::out_of_range を送出します。

operator[](std::size_t index) 配列の指定位置の要素を参照します。添字は 0 から始まり、要素の挿入は 行いません。配列以外の場合は std::logic_error、範囲外の場合は std::out_of_range を送出します。

親の Dataset を置き換えると、その要素への参照は無効になります。

value() const noexcept 保持する Value への const 参照を返します。std::get または std::get_if で型を指定して値を取得できます。型が異なる場合、 std::get は std::bad_variant_access を送出し、std::get_if は null ポインターを返します。

コメント

comments() const noexcept コメント文字列の配列への const 参照を、保存順で返します。

set_comments(std::vector<std::string> comments) コメントを置き換えます。先頭のコメント記号は付けずに指定します。 文字列中の改行は保存時に複数のコメント行になります。 YAML と TOML への保存では有効な UTF-8 が必要で、未対応の制御文字と Unicode の行区切り文字は使えません。TOML で構文上配置できないコメントは 省略されます。CSV と JSON にはコメントを保存しません。 代入または Load の成功時には既存のコメントも置き換わります。

ファイルの読み書き

Load(const std::string& path) 拡張子により CSV、JSON、YAML、TOML の形式を選択して読み込みます。 対応する拡張子は .csv、.json、.yaml、.yml、.toml で、 大文字と小文字は区別しません。コメントは読み込みません。 成功時は既存の値とコメントを置き換え、失敗時は Dataset を変更しません。 入出力エラー、不正な入力、未対応の拡張子や値に対して std::runtime_error を送出します。

static Parse(const std::string& text, const std::string& format = "json") CSV、JSON、YAML、TOML のテキストを解析します。format は大文字小文字を区別しない csv、json、yaml、yml、toml のいずれかで、省略時は json です。ネスト上限を含め Load と同じ規則に従い、コメントは読み込みません。上限より深くネストした値として保持された文字列を展開するときに使います。入力が不正な場合や未対応の形式では std::runtime_error を送出します。

static LoadDirectory(const std::string& path, bool recursive = false) ディレクトリ内の対応ファイルを読み込み、パスと Dataset の組を パス順の std::list<std::pair<std::string, Dataset>> で返します。 recursive が true の場合のみサブディレクトリを再帰的に走査します。 対応外の拡張子は無視します。ファイルとディレクトリのシンボリックリンクを たどり、同じ対象に複数のパスで到達した場合はパスごとに読み込みます。 返されるパスには指定されたディレクトリ名とリンク名を保持します。 ファイルのリンク自身の拡張子で形式を選択します。 循環、リンク切れ、読み取れないエントリー、読み込みに失敗したファイルは 標準エラーに警告を出してスキップします。開始ディレクトリを開けない場合は std::runtime_error を送出します。コメントは読み込みません。

Save(const std::string& path) const 拡張子により形式を選択して保存します。CSV は同じキーを持つ空でない 文字列値のマップの配列を必要とし、空配列は空ファイルとして保存されます。 TOML のルートはマップでなければならず、null は保存できません。 非有限の浮動小数点数は保存できません。YAML と TOML では可能な範囲で コメントを保存します。シリアライズはファイルを開く前に行いますが、 書き込み中の入出力エラーではファイルが途中までしか保存されない場合や 切り詰められる場合があります。入出力エラー、未対応の拡張子や、 形式で表現できない値またはコメントに対して std::runtime_error を送出します。

CSV の読み込みでは先頭行を列名とし、各行を文字列値のマップとして扱います。 列名の重複や列数の不一致はエラーです。YAML は対応する基本スカラー型を解決し、 複数文書、重複アンカー、再帰的な別名、未対応のタグを拒否します。 TOML の日時型および非有限数は読み込めません。

Dataset::kMaxNestingDepth（256）より深くネストしたマップと配列はツリーとしては読み込まれず、コンパクトな JSON テキストを保持する文字列になり、Parse で変換できます。これらの値の内部では YAML のアンカーを定義できず、上限の 2 倍を超える TOML は拒否され、Save は上限を超える値を拒否します。合計 1,000,000 個を超える値に展開される YAML の別名はエラーです。

使用例

#include <Dataset.h>
#include <string>
#include <variant>

Dataset data;
data["server"]["host"] = "localhost";
data["server"]["host"].set_comments({"Server address"});
data.Save("config.yaml");

Dataset loaded;
loaded.Load("config.yaml");
const auto& host = std::get<std::string>(
    loaded["server"]["host"].value());

データ駆動テスト

次の GoogleTest の例はプロジェクトルートから実行します。 Dataset で Tests/data/server-config の 2 ファイルを読み込み、独立した ServerConfig モデルのエンドポイントと有効状態を期待値と比較します。 ファイル数と空ケースの検査により、 データファイルの読み込み漏れを検出できます。 各ファイルの cases は入力値 input と期待値 expected を持ちます。

Tests/data/server-config/basic.json

{
  "cases": [
    {
      "input": {"host": "localhost", "port": 8080, "enabled": true},
      "expected": {"endpoint": "localhost:8080", "enabled": true}
    },
    {
      "input": {"host": "127.0.0.1", "port": 0, "enabled": false},
      "expected": {"endpoint": "127.0.0.1:0", "enabled": false}
    }
  ]
}

Tests/data/server-config/alternate.toml

[[cases]]
[cases.input]
host = "example.net"
port = 443
enabled = false

[cases.expected]
endpoint = "example.net:443"
enabled = false

#include <cstddef>
#include <cstdint>
#include <string>
#include <utility>
#include <variant>

#include <gtest/gtest.h>
#include "Dataset.h"

class ServerConfig {
 public:
  ServerConfig(std::string host, std::int64_t port, bool enabled)
      : host_(std::move(host)), port_(port), enabled_(enabled) {}

  std::string endpoint() const { return host_ + ":" + std::to_string(port_); }
  bool enabled() const { return enabled_; }

 private:
  std::string host_;
  std::int64_t port_;
  bool enabled_;
};

TEST(ServerConfigTest, BuildsEndpointAndStoresEnabledState) {
  const auto files = Dataset::LoadDirectory("Tests/data/server-config");
  ASSERT_EQ(files.size(), 2u);
  for (const auto& [path, dataset] : files) {
    SCOPED_TRACE(path);
    const auto& cases = std::get<Dataset::Array>(dataset["cases"].value());
    ASSERT_FALSE(cases.empty());
    for (std::size_t i = 0; i < cases.size(); ++i) {
      SCOPED_TRACE(i);
      const Dataset& input = cases[i]["input"];
      const Dataset& expected = cases[i]["expected"];
      const ServerConfig server(std::get<std::string>(input["host"].value()),
                                std::get<std::int64_t>(input["port"].value()),
                                std::get<bool>(input["enabled"].value()));
      EXPECT_EQ(server.endpoint(),
                std::get<std::string>(expected["endpoint"].value()));
      EXPECT_EQ(server.enabled(), std::get<bool>(expected["enabled"].value()));
    }
  }
}
