CppDatasetUtil API

名称

CppDataSet - 带可选注释的递归 Dataset 值

用法

#include <Dataset.h>
class Dataset;

描述

Dataset 可以保存 null、布尔值、有符号 64 位整数、double、字符串、 映射或数组。映射和数组的元素也是 Dataset，每个值均可单独设置注释。 映射按键排序，数组保持元素顺序。复制和移动同时处理值及其注释。

类型和构造函数

Dataset::Map 是 std::map<std::string, Dataset>，Dataset::Array 是 std::vector<Dataset>，Dataset::Value 是包含支持类型的 std::variant。 默认构造函数创建不带注释的 null。也可以从 nullptr、bool、int、 std::int64_t、double、const char*、std::string、Map 和 Array 构造。 向 const char* 传入空指针会抛出 std::invalid_argument。

其他整数类型（如 long long、std::size_t 或 unsigned）会保存为有符号 64 位整数；超出 int64 范围的无符号值会抛出 std::out_of_range。除 const char* 外的指针不会转换为 bool，而是在编译时被拒绝。

访问

operator[](const std::string& key) 访问映射项。可修改的 null 值会先转换为空映射，不存在的键会以 null 值插入；父值的注释保持不变。const 访问不会修改数据，键不存在时抛出 std::out_of_range。对非映射值访问会抛出 std::logic_error。

operator[](std::size_t index) 访问数组元素，不会插入元素。索引从 0 开始。值不是数组时抛出 std::logic_error，索引越界时抛出 std::out_of_range。替换父 Dataset 会使其元素的引用失效。

value() const noexcept 返回 Value 的 const 引用。类型不匹配时，std::get 抛出 std::bad_variant_access，std::get_if 返回空指针。

size() const noexcept 返回映射或数组的元素数量；其他值返回 0。

contains(const std::string& key) const noexcept 当值是包含 key 的映射时返回 true。

push_back(Dataset value) 向数组末尾追加元素。null 值会先变为空数组并保留其注释。其他类型会抛出 std::logic_error。

erase(const std::string& key) 删除映射项并返回该项是否存在。非映射值会抛出 std::logic_error。

erase(std::size_t index) 删除数组元素，后面的元素前移。非数组值抛出 std::logic_error，索引越界抛出 std::out_of_range。

value() noexcept 返回 Value 的可修改引用。赋入其他类型的值会替换该值，注释保持不变。

operator==, operator!= 递归比较值和注释。NaN 与自身也不相等。

注释

comments() const noexcept 返回注释的 const 引用，顺序与存储顺序相同。

set_comments(std::vector<std::string> comments) 替换注释。文本不应以 # 开头，换行会产生多个注释行。YAML 和 TOML 要求有效的 UTF-8，并拒绝不支持的控制字符及 Unicode 行分隔符。 无法按 TOML 语法放置的注释会被省略。CSV 和 JSON 不保存注释。 赋值或成功调用 Load 也会替换现有注释。

文件

Load(const std::string& path) 根据扩展名 .csv、.json、.yaml、.yml 或 .toml 选择 CSV、JSON、YAML 或 TOML，扩展名不区分大小写。不读取注释。成功时替换值和注释； 失败时 Dataset 保持不变。输入输出错误、无效输入、不支持的扩展名 或值会导致 std::runtime_error。

static Parse(const std::string& text, const std::string& format = "json") 解析 CSV、JSON、YAML 或 TOML 文本。format 是不区分大小写的名称：csv、json、yaml、yml 或 toml，默认为 json。规则（包括嵌套限制）与 Load 相同，不读取注释。可用它展开因嵌套超过限制而保留的字符串。输入无效或格式不受支持时抛出 std::runtime_error。

static LoadDirectory(const std::string& path, bool recursive = false) 返回由路径和 Dataset 组成的 std::list，按路径排序。仅当 recursive=true 时遍历子目录，忽略不支持的扩展名。会跟随文件和目录的符号链接； 同一目标通过多个路径到达时，每个路径都会读取一次。返回路径保留 指定的目录和链接名称。文件链接本身的扩展名决定格式。循环、失效链接、 无法读取的条目及加载失败的文件会被跳过，并向标准错误输出警告。 无法打开起始目录时抛出 std::runtime_error。不读取注释。

Save(const std::string& path) const 根据扩展名保存。CSV 要求数组中的映射非空、具有相同的键且值均为 字符串；空数组保存为空文件。TOML 根节点必须为映射且不支持 null。 不能保存非有限浮点数。YAML 和 TOML 保存可表示的注释。内容先写入临时文件再重命名覆盖目标，因此写入出错时现有文件保持不变。 会跟随符号链接并保留权限。 输入输出错误、不支持的扩展名以及无法表示的值或注释会导致 std::runtime_error。

CSV 将首行用作列名，之后每行读取为字符串映射。重复列名和列数不一致 均为错误。YAML 解析支持的基本标量类型，并拒绝多文档、重复锚点、 递归别名和不支持的标签。TOML 日期时间及非有限数值不能读取。

读取 CSV 时会忽略开头的 UTF-8 BOM 和空行；单列文件中的空值保存为 ""，以免记录丢失。文件路径在所有平台（包括 Windows）上都按 UTF-8 的 std::string 处理，LoadDirectory 返回的名称也是 UTF-8。使用 Windows DLL 时，调用方的 CRT 类型（/MD 或 /MT，Debug 或 Release）和 _ITERATOR_DEBUG_LEVEL 必须与 DLL 一致；否则会在链接时因未解析的 CppDatasetUtilAbi1_* 符号而报错。

嵌套深度超过 Dataset::kMaxNestingDepth（256）的映射和数组不会作为树读取，而是以保存其紧凑 JSON 文本的字符串保留，可用 Parse 转换。这些值内部不能定义 YAML 锚点，嵌套超过限制两倍的 TOML 会被拒绝，Save 也会拒绝超过限制的值。总共展开为超过 1,000,000 个值的 YAML 别名属于错误。

示例

#include <Dataset.h>
#include <string>
#include <variant>
Dataset data;
data["server"]["host"] = "localhost";
data["server"]["host"].set_comments({"Server address"});
data.Save("config.yaml");
Dataset loaded;
loaded.Load("config.yaml");
const auto& host = std::get<std::string>(
    loaded["server"]["host"].value());

数据驱动测试

以下 GoogleTest 示例从项目根目录运行。它读取 Dataset 读取 Tests/data/server-config 中的两个文件，并比较独立的 ServerConfig 模型的端点和启用状态与期望值。文件数量和非空用例检查有助于 发现被跳过的数据文件。 每个文件的用例都包含输入值 input 和期望值 expected：

Tests/data/server-config/basic.json

{
  "cases": [
    {
      "input": {"host": "localhost", "port": 8080, "enabled": true},
      "expected": {"endpoint": "localhost:8080", "enabled": true}
    },
    {
      "input": {"host": "127.0.0.1", "port": 0, "enabled": false},
      "expected": {"endpoint": "127.0.0.1:0", "enabled": false}
    }
  ]
}

Tests/data/server-config/alternate.toml

[[cases]]
[cases.input]
host = "example.net"
port = 443
enabled = false

[cases.expected]
endpoint = "example.net:443"
enabled = false

#include <cstddef>
#include <cstdint>
#include <string>
#include <utility>
#include <variant>

#include <gtest/gtest.h>
#include "Dataset.h"

class ServerConfig {
 public:
  ServerConfig(std::string host, std::int64_t port, bool enabled)
      : host_(std::move(host)), port_(port), enabled_(enabled) {}

  std::string endpoint() const { return host_ + ":" + std::to_string(port_); }
  bool enabled() const { return enabled_; }

 private:
  std::string host_;
  std::int64_t port_;
  bool enabled_;
};

TEST(ServerConfigTest, BuildsEndpointAndStoresEnabledState) {
  const auto files = Dataset::LoadDirectory("Tests/data/server-config");
  ASSERT_EQ(files.size(), 2u);
  for (const auto& [path, dataset] : files) {
    SCOPED_TRACE(path);
    const auto& cases = std::get<Dataset::Array>(dataset["cases"].value());
    ASSERT_FALSE(cases.empty());
    for (std::size_t i = 0; i < cases.size(); ++i) {
      SCOPED_TRACE(i);
      const Dataset& input = cases[i]["input"];
      const Dataset& expected = cases[i]["expected"];
      const ServerConfig server(std::get<std::string>(input["host"].value()),
                                std::get<std::int64_t>(input["port"].value()),
                                std::get<bool>(input["enabled"].value()));
      EXPECT_EQ(server.endpoint(),
                std::get<std::string>(expected["endpoint"].value()));
      EXPECT_EQ(server.enabled(), std::get<bool>(expected["enabled"].value()));
    }
  }
}
